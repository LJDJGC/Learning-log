### 💡 学びのポイント
**新規習得：**
- `useMemo` の基本形：`useMemo(() => { ... }, [deps])` で `deps` が変わった時だけ再計算する。`[sessions]` を入れないと毎回再計算、入れると `sessions` 変更時のみ

**理解深化：**
- `formatMonthLabel` の `getMonth() + 1` は0始まり補正。`export` は関数の外（トップレベル）に置かないとスコープエラー＋テストから呼べない
- `["", 0]` の `0` は「0分以下はdominantにしない」閾値。`-1` にすると0分でも採用されるが本アプリは `duration>=1` なので通常は同じ

**トラブルシューティング：**
- 昨日：`export function formatMonthLabel` を `aggregateByData` の中に書いて `TS1127 Invalid character` ×5 → 外に出して解消
- 今日：書きかけの `useMemo` がコンポーネント関数の外に浮いており、`}, [sessions]` と `return` が未完。`Math.max(...[])` は `-Infinity` になるため `main` 実装のように `for` ループで `max=0` から比較する方が安全

### 💡 Key Learnings
**Newly Acquired:**
- Basic form of `useMemo`: `useMemo(() => { ... }, [deps])` recomputes only when `deps` change. Without `[sessions]` it recomputes every render

**Deeper Understanding:**
- `getMonth() + 1` in `formatMonthLabel` compensates zero-based month. `export` must be at top level, otherwise scope error and untestable
- `["", 0]` in `reduce` is a threshold "ignore 0 or less". With `-1`, even 0-minute records would be adopted, but the app uses `duration>=1` so normally identical

- Yesterday: `export function formatMonthLabel` inside `aggregateByData` with escaped `\${...}` caused 5× `TS1127` → moved outside and fixed backticks
