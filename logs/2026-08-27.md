### 💡 学びのポイント
**新規習得：**
- `useMemo(() => { ... }, [sessions])` の `return { dayMap: map, maxDayMinutes: max }` はオブジェクトで返し、外で分割代入する形。这样写的好处是可以从一个 useMemo 里同时取出多个计算结果

**理解深化：**
- `//` コメントは `useMemo` の中に入れるべきではない — 該当行の末尾か上の行に置くと見返しやすい
- 「max = 0 で初期化」は「max に 0 を入れる」と言い換えると自然な日本語
- `TS2786: GrassCalendar cannot be used as JSX component` → `return` がないとコンポーネントが `void` として判定される

**トラブルシューティング：**
- コメントを `useMemo` の中に入れていたら構造が分かりにくかった → 各行の末尾に移動
- 写経と同じだと感じた → 「見ずに書く」「自分の言葉で説明する」に切り替えると定着度が上がる

export default function GrassCalendar({ sessions, weeks = 12 }: Props) {
    const { dayMap, maxDayMinutes } = useMemo(() => {
        const map = aggregateByData(sessions);
        let max = 0;
        for (const day of map.values()) { if (day.total > max) max = day.total; }
        return { dayMap: map, maxDayMinutes: max };
    }, [sessions]);
    // return <div>草カレンダー</div>; // 次に追加する
}
