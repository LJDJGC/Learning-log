### 💡 Key Learnings
**Newly Acquired:**
- Placement of `export` matters for scope: writing `export function formatMonthLabel` inside `aggregateByData` causes "Invalid character / Unexpected keyword" and makes it uncallable from outside/tests. It must be outside, after `return dayMap; }`
- Template literals use backticks `` ` `` with `` `${date.getFullYear()}年${date.getMonth() + 1}月` ``. `getMonth()` is zero-based, so `+1` is mandatory

**Deeper Understanding:**
- `["", 0]` in `reduce` is a threshold meaning "ignore 0 or less". With `-1`, even a 0-minute record would be adopted. Since the app uses `duration >=1`, behavior is identical for normal data — `0` is the safe choice for abnormal cases
- `reduce` accumulator is a `[type, duration]` pair, updated when `duration > max[1]`, and the final `[0]` extracts just the type name

**Troubleshooting:**
- `TS1127 Invalid character` ×5 → `export function formatMonthLabel` was written inside `aggregateByData` with escaped `\${...}`. Fixed by moving it outside and using correct backticks
- `TS1192 has no default export` → Main component (`GrassCalendar` default export) not yet implemented. Expected error until STEP 6 is complete
