  - `collection("sessions")` → どのテーブルか

```tsx
// Firebase 認証状態の監視 + データ読み込み
useEffect(() => {
    const unsubscribe = onAuthStateChanged(auth, (currentUser) => {
        setUser(currentUser);
        if (currentUser) {
            // localStorage を先に表示
            const localData = localStorage.getItem("sessions");
            if (localData) setSessions(JSON.parse(localData));
            setLoading(false);

            // Firestore は裏で試行
            (async () => {
                const q = query(
                    collection(db, "sessions"),
                    where("userId", "==", currentUser.uid)
                );
                const snap = await getDocs(q);
                // ... データ変換 & セット
            })();
        }
    });
    return () => unsubscribe();
}, []);
```

**Newly Acquired:**
- **How `onAuthStateChanged` works**:
  - Tells Firebase "notify me when login state changes"
  - First call returns current state immediately, then notifies on changes
  - Returns `unsubscribe()` for cleanup (required to prevent memory leaks)
- **Firestore data transformation**:
  - `docSnap.data()` returns raw data from Firestore
  - Must transform to app types (Session) before using `setSessions`

**Deeper Understanding:**
- **localStorage-first pattern**:
  - UI shows immediately even if Firestore is blocked
  - Firestore syncs in background, overwrites on success
- **`query` + `collection` + `where` separation of concerns**:
  - `collection("sessions")` → which table
  - `where("userId", "==", uid)` → filter condition
  - `query(...)` → combine into a request
  - `getDocs(q)` → execute the request
