- **JSXレイアウト崩れは「コード文字列」ではなく「構造」を見る**:
  「StudyWorkout」という文字列はコードのどこにも存在しないのに、画面上で

  色枠のspan（`h-3 w-3` = 12px角）の中に直接テキスト「Study」を入れていたため、
  文字が12px幅に押し込まれて Workout と連結して見えた。Workout側は正しい構造
  （色枠と文字を別要素で分離）だったので、差分を突き合わせて特定できた。

- **色枠＋テキストの凡例は「flex items-center gap-1」で分離する**:
  ```
  // NG: 色枠の中にテキストを入れる
  <span className="inline-block h-3 w-3 rounded-sm bg-blue-400">Study</span>

  // OK: 色枠とテキストを別要素にする
  <span className="flex items-center gap-1">
      <span className="inline-block h-3 w-3 rounded-sm bg-blue-400" />
      Study
  </span>
  ```

**理解深化：**
- **AI評価者の指摘は検証してから判断する**（前回の教訓の再利用）：
  実画面で「StudyWorkoutが崩れている」という指摘は、ローカルで文字列検索しても

### 💡 Key Learnings

**Newly Acquired:**
- **For JSX layout bugs, inspect the structure, not the string**:
  "StudyWorkout" exists nowhere in the code, yet "Study" and "Workout" visually
  merged into one broken label. The cause was in the legend markup: the text
  "Study" was placed directly inside the color-swatch span (`h-3 w-3` = 12px box),
  so it got squeezed into 12px width and appeared glued to "Workout". The
  Workout side had the correct structure (swatch and text as separate elements),
  so comparing the two implementations pinpointed the bug.

- **Legend items (swatch + text) should use "flex items-center gap-1"**:
  ```
  // NG: text inside the swatch
  <span className="inline-block h-3 w-3 rounded-sm bg-blue-400">Study</span>

  // OK: swatch and text as separate elements
  <span className="flex items-center gap-1">
      <span className="inline-block h-3 w-3 rounded-sm bg-blue-400" />
      Study
  </span>
  ```

**Deeper Understanding:**
- **Verify reviewer feedback before judging it** (reusing last time's lesson):
  The "StudyWorkout is broken" feedback found no string match locally, but the
  deployed screen really showed the breakage. Don't conclude "not in code =
  feedback is wrong"; dig into the component structure instead.

**Troubleshooting:**
- "StudyWorkout" not found by search → switched from string search to DOM
  structure analysis; compared the broken (Study) vs correct (Workout)
