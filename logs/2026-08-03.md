### 💡 学びのポイント

**新規習得：**
- **比率ベースのレベル判定**:
  0分 → 0 / maxMinutes=0 → 1 / ratio = minutes / maxMinutes で 0〜4 の5段階に判定。
  ratio≤0.1→0 / ≤0.25→1 / ≤0.5→2 / ≤0.75→3 / それ以上→4。
  絶対値（40/60/80分）より柔軟で、データの規模に依存しない判定ができる。

- **maxMinutes の設計には2つの選択肢がある**:
  ① 総合max（全type共通の1つの最大値）
  ② type別max（typeごとに最大値を持つ）
  総合maxは実装が単純だが、学習(120分)と筋トレ(40分)のように目安時間が違うtypeがあると、
  目安時間が短いtypeはどんなに頑張っても高レベルに到達しない不公平が生まれる。
  今回は「それぞれの種目で自分がどれだけ頑張ったか」を見たいので type別max を選択。

**理解深化：**
- **除算の前に0チェックが必要**:
  `maxMinutes === 0` のときに `ratio = minutes / maxMinutes` を計算すると `Infinity` になる。
  0除算を避けるため、if文の順序で「0分チェック → maxMinutes=0チェック → 除算」の順に処理する必要がある。
  ルールを並べるときは「例外→通常」の順番が安全。

- **`{ }` はオブジェクトの記法**:
  `const getLevel = { if () }` と書くとオブジェクトリテラルになってしまい関数にならない。
  関数は `function getLevel() {}`（関数宣言）か `const getLevel = () => {}`（アロー関数）で書く。
  「書く対象が関数なのかオブジェクトなのか」を最初に意識する。

```tsx
// minutes: その日のそのtypeの合計時間 / maxMinutes: そのtypeの全期間最大値
function getLevel(minutes: number, maxMinutes: number): number {
  if (minutes === 0) return 0;
  if (maxMinutes === 0) return 1; // 0除算を防ぐため除算より先に処理
  const ratio = minutes / maxMinutes;
  if (ratio <= 0.1) return 0;
  if (ratio <= 0.25) return 1;
  if (ratio <= 0.5) return 2;
  if (ratio <= 0.75) return 3;
  return 4;
}
```

### 💡 Key Learnings
**Newly Acquired:**
- Ratio-based level scoring: 0 min → 0 / maxMinutes=0 → 1 / ratio = minutes/maxMinutes → levels 0-4.
  ratio≤0.1→0 / ≤0.25→1 / ≤0.5→2 / ≤0.75→3 / otherwise→4.
  More flexible than absolute thresholds (40/60/80 min) because it does not depend on data scale.

- There are two design options for maxMinutes:
  ① Global max (one shared value across all types)
  ② Per-type max (each type has its own max)
  The global max is simpler but unfair when types have different typical durations
  (e.g., study=120min vs workout=40min) - the shorter type can never reach a high level.
  Chose per-type max because we want to show "how hard I pushed each type".

**Deeper Understanding:**
- Zero-check must come before division: if maxMinutes===0, computing minutes/maxMinutes yields Infinity.
  Order the if statements as "exceptions first, then normal path" to stay safe.

- `{ }` is object literal syntax: `const getLevel = { if () }` is not a function.
  Use `function getLevel() {}` (declaration) or `const getLevel = () => {}` (arrow function).
  First decide whether you are writing a function or an object.
