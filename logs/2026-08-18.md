### 💡 学びのポイント
**新規習得：**
- 関数の**戻り値の型は「呼び出し側の使い方」から逆算する**。`dayMap.get(日付)` で引くなら `Map<string, DayData>` と書く。型の位置にメソッド呼び出し（`dayMap.get`）は書けない
- **変数の「持ち主」を意識する**: `total` や `byType` は独立した変数ではなく、Map の中にしまった `DayData` オブジェクトのプロパティ。**まず `dayMap.get(日付)` で DayData を取り出してから** `.total` や `.byType` を操作する

**理解深化：**
- `aggregateByData` は2フェーズ構成: ①sessions を `s.date` キーで Map に集計（`total` と `byType[s.type]` に加算）②Map をループして `byType` の最大値の type を `dominantType` に決定
- 分岐条件は「日付が null か」ではなく「**その日が Map に存在するか**」（`dayMap.has()`）。無い日だけ初期値を `set` し、どちらの分岐でも `dayMap.get(session.date)!` で取得する（`!` は「必ず存在する」の宣言・非nullアサーション）
- `getLevel` の5段階は比率基準（0.1 / 0.25 / 0.5 / 0.75）で、**境界値（`<` か `<=` か）まで正確に覚える**必要がある
- `DayData` は `date` フィールドも持つ設計だった（キーとは別にデータ側にも日付情報を持つ）
- 戻り値の型を宣言した関数は**必ず値を返す**（`return dayMap;` を忘れない）

**トラブルシューティング：**
- `const aggregateByData = (sessions: Session[]): dayMap.get : DayData => {`
  → コンパイル不能な構文エラー。`.get` は実行時呼び出しの書き方であり、型注釈の位置には置けない。**「使う側の変数名」と「関数の戻り値の型」を混同していた**のが原因
  → 正しくは `: Map<string, DayData>` と宣言
- 書きかけのループで `s` / `total` / `byType` が未定義（`Cannot find name` エラー）
  → ループ変数は `session` であり `s` ではない。`total` / `byType` は**取得した DayData のプロパティ**として `day.total` / `day.byType` と書く

```tsx
type DayData = {
    total: number;
    dominantType: string;
    byType: Record<string, number>;
}

const aggregateByData = (sessions: Session[]): Map<string, DayData> => {
    const dayMap = new Map<string, DayData>();

    for (const session of sessions) {
        // Phase 1: 日が無ければ初期値を作り、あれば取得して加算
        if (!dayMap.has(session.date)) {
            dayMap.set(session.date, { total: 0, byType: {}, dominantType: "" });
        }
        const day = dayMap.get(session.date)!;
        day.total += session.duration;
        day.byType[session.type] = (day.byType[session.type] || 0) + session.duration;
    }
    // Phase 2: byType の最大値の type を dominantType にセット
    // return dayMap;
};
```
